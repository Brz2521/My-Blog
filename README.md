# My Blog

A personal blog website built with **Python**, **Django**, **HTML**, and **CSS** that showcases my interests in **music technology**, programming, and web development.

This project serves as both a learning experience and a place to share my thoughts on music production, digital audio technology, and software development.

---

## About

My Blog is a Django-powered web application where I write about topics that inspire me, including:

- Music Technology
- Digital Audio Workstations (DAWs)
- Music Production & Recording
- Python Programming
- Web Development
- Learning New Technologies

The goal of this project is to practice full-stack web development while building a clean and responsive blog website.

---

## Features

- Responsive blog homepage
- Individual blog post pages
- Modern user interface
- Navigation between pages
- Styled with custom CSS
- Dynamic page rendering using Django
- Organized project structure following Django best practices
